# CompTIA Security+ SY0-701 quizzes

Practice quizzes for CertMaster modules 1–5. Original items — not exam dumps. Not affiliated with CompTIA.

## Launch after you download it

1. On GitHub, choose **Code → Download ZIP** and unzip the folder.
2. Start the quiz:

- **Windows:** double-click `Launch-Windows.bat`
- **Mac:** double-click `Launch-Mac.command`. If macOS blocks it, right-click the file and choose **Open**.
- **Linux:** double-click `Launch-Linux.sh`, or run `./launch.sh` in a terminal.

If Node.js is installed, the launcher serves the quiz on your computer and opens it in your browser. Leave that window open while you study, then close it when you are done. If Node.js is not installed, the launcher opens `index.html` instead.

You can also open `index.html` yourself, or run `npm start` when Node.js is installed. Scores stay in that browser.
